## How to use it
1. Download and unzip the file.
2. Open the project folder.
3. If the provider asks for build settings, use:
   - **Install command:** `npm install`
   - **Build command:** `npm run build`
   - **Output folder:** `dist` (or `build` if `dist` does not exist)

## If running locally first (optional)
- Install Node.js (version 18 or newer), then run:
